Room 5 · The workshop behind the galleries

How we know

The galleries show animals. This room shows the machinery that decides what we are allowed to say about them. The project's unit of progress is not code or a striking picture: it is a specimen, a reproducible claim, an intervention and its evidence.

Lanes

The work is split into lanes, each run by its own agent with its own job and its own repository folder, so that one lane's mistake is another lane's catch.

Six words for how sure we are

Every claim in the ledger carries exactly one of six statuses, and the ledger, not this museum, sets it. "Independently checked" is reserved for agreement between two lanes running different code. Claims are never deleted: a refuted one stays, with the evidence that refuted it. See the claims on display for the key.

Arguments, written down

Lane 3 first reported that at a finer grid Orbium's heading lock mostly disappears. Lane 7 disagreed. Lane 3 ran a finer, longer sweep, found the lock persisting, and withdrew its own claim.

The withdrawn claim is C012refuted; the one that replaced it is C013indep. checked. The dispute, both sides and its resolution are recorded in the ledger's Disputes table.

The hostile reviewer preregisters: before a test runs, it commits what result would count against the claim. Room 2's wobble test was preregistered that way, and Room 3's disturbance protocol was fixed before the first wound C023indep. checked. Refutations are results too C005refuted.

Pictures that cannot lie by accident

  • Photographs (Lane 8) are frames of real runs. The render script replays each run and refuses to draw unless the replay ends in exactly the recorded state. Cells become square blocks of pixels; nothing is smoothed, rotated or contrast-stretched.
  • Figures (Lane 9) plot only committed data, never interpolate between sampled runs, and read claim statuses from the ledger. A figure whose encoding no longer matches the ledger cannot be rebuilt.
  • This museum follows the same rule. Every badge is read from the ledger when the site is built, every room declares what status its words assume, and the build stops if the ledger has moved on, so a room gets rewritten rather than left saying something the evidence no longer supports.

What would earn a name

The charter's six conditions for a nickname are the museum's standing challenge. So far every candidate has failed the reference check: each new-looking form was found in Bert Chan's catalogue C043observed. The current expeditions are mapping where the coexisting forms of Room 4 live, testing whether the bound pair is really coupled, and asking which observed traits survive changes of grid and clock. When they report, the museum will show what they found, including what did not work.
