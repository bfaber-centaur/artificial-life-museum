# Specimens

One dossier per specimen, named by stable ID (e.g. `S001-orbium.md`). Required fields are listed in `../charter.md` under "Specimen dossier". Nicknames only after the stable ID exists.

ID blocks: `S0xx` reference specimens (Lane 1); `S1xx` field candidates (Lane 6). Lane 6
specimens are registered in `alm.specimens`, so `python -m alm.run --specimen S101` works.

| ID | What | Rule | Status |
| --- | --- | --- | --- |
| S001 | Orbium unicaudatus (`O2u`) | S001 baseline | reference |
| S101 | bound Orbium pair (Synorbium ignis `O4i` branch) | S001 baseline | catalogued; fissions to Orbium under port injury |
| S102 | circler (Gyrorbium gyrans `OG2g` branch) | μ 0.155, σ 0.020 | catalogued; dies at R 26 at this rule |
| S103 | static binary ring (Circium lithos apertus `C0la` branch) | μ 0.155, σ 0.020 | catalogued; exact clip fixed point |
